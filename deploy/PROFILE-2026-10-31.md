## Rollback

Point `/opt/luli/current` back to `/opt/luli/releases/014e768` and restart
`luli.service` only if no user has saved structured profiles with the new
release. The older client does not validate the new array fields. Once new
profiles exist, prefer a forward fix or a compatible frontend rollback; do not
restore the pre-release database over subsequent user edits.
