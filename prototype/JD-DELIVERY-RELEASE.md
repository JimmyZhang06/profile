# JD 整份投递稿发布记录

日期：2026-11-02。线上地址：https://resume.jimmyzhang.xyz/ 。代码版本：`ad13d4c`；上一版本：`141fcea`。

## 使用路径

「按 JD 生成」→ 填写岗位 → 核对本次资料和模型 → 生成独立草稿 → A4 预检与事实核对 → 系统打印保存 PDF。新建简历和目标岗位页也提供生成入口。未连接模型时明确标为本地关键词选材。

默认单栏 A4、11 pt 正文、15 mm 留白；超长时先采用有原文依据的短表达，再调整间距，正文最低 10.5 pt。保持原始材料和已有简历。姓名、联系方式、日期和教育身份不由模型改写。每条改写引用本次资料中的原文；没有依据的缺项呈现于检查栏，不补成事实。

整份生成沿用既有连接、所有权、额度与出站规则。新连接默认最大输出 8192 token，既有云连接保持原配置；可在对应模型设置调整。达到输出上限或断流不会保存残缺简历。
