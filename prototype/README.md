# 履历 · 对话与简历工作空间

面向个人求职的本机与个人云工作区：从项目素材出发，针对岗位组织简历，通过对话提出修改，再逐项审核。初始内容是明确标注的虚构示例。

## 账号与云工作区 · 2026-10-30

已增加独立 Node.js API、Better Auth 邮箱验证码、邀请制准入、按账号隔离的工作区和 `/admin` 管理后台。本机模式继续可用；首次登录选择导入资料，云端保存支持断网草稿、过期重登、版本冲突和重复导入保护。后台提供用户/邀请、平台 AI、固定版本模板、调用记录及操作记录，并要求额外验证器验证。

运行 `npm run dev` 同时启动前端和 API。开发模式使用本机 PGlite 与文件开发邮箱，不发送真实邮件。开发管理员为 `owner@luli.local`；正式跨设备使用仍需部署 PostgreSQL、HTTPS、SMTP 和独立密钥。完整操作、配置与数据边界见 [账号与部署说明](CLOUD.md)。

## 当前功能

- 独立的岗位简历、项目素材库、个人资料、JD 和对话上下文。
- 项目素材、岗位、个人资料、设置、版本与导出在工作区内切换页面，保留侧栏和返回简历入口。
- 草稿自动保存到本机浏览器；版本保存/恢复、撤销/重做、多窗口冲突提示。
- 完整项目档案：背景、目标、职责边界、行动决策、实际成果、数据依据、难点、协作、复盘和原始记录；支持追加 TXT/Markdown、归档恢复和全文关键词搜索。
- 按 JD 选择项目、提取岗位要点；素材原件、简历关联快照与岗位表达分别保存，旧要点兼容保留。
- 原文与建议对照、逐项采用、原文变化后阻止旧建议覆盖。
- 消息编辑、停止/重试、自动跟随最新回复、选中段落作为对话上下文。
- 回复使用履历折页 Logo：等待时轻微呼吸与明暗流动，输出时减弱，完成、停止或失败后静止；状态集中在身份行，本地规则保持明确标识，支持减少动态效果偏好。
- 新回复逐字显示，支持立即停止，历史消息不重播；长文本和链接自动换行。桌面拖动中间分隔线调整预览宽度，双击还原，方向键微调，刷新保留比例。
- 预览底栏统一为 44px：阅读模式显示当前字号，A4 模式集中提供减小、比例菜单和放大，专注编辑独立放置；菜单向上展开，适配窄预览和手机。
- 「排版与模板」分为文字、间距和模板三组。桌面临时接替对话栏，让简历保持完整高度；手机将工具放在预览下方。完成后恢复对话草稿及原分栏宽度。支持 3 种字体、正文字号 9–16pt（步进 0.5pt）、章节与姓名字号、行距 1.2–2.4 倍、段落/章节间距及页面留白。屏幕阅读字号独立提供 14/15/16/17/18/20/22。
- 双击简历段落，或选中后点「编辑文字」，可对局部文字加粗、斜体、下划线或清除格式；支持 Ctrl/⌘ B、I、U、局部撤销/重做、Ctrl/⌘ Enter 保存和 Esc 取消，编辑时同步预览。
- 五套真实排版：经典商务、现代简约、编辑叙事、清晰双栏、紧凑专业；缩略图使用当前简历内容，切换后保留文字与重点格式，支持撤销。
- 可关闭的 AI 功能，以及可配置的 Chat Completions 兼容连接。本地整理使用明确的确定性规则，不模拟真实模型回复。
- Markdown 导出、JSON 备份/导入、浏览器打印入口。
- 全工作区黑白灰主题：左下角「外观」切换浅色、深色或跟随系统，刷新保留选择。主题偏好独立于简历数据保存。
- 单行文档工具栏统一文件、JD、选材、编辑与导出入口；素材页在列表旁展示当前选材和顺序，手机使用折叠摘要；JD 保存后可直接继续选材。

## 可读性调整 · 2026-10-28

- 对话正文桌面 17px，手机 16px，行高 1.85；段落、标题、列表和重点词分别排版。
- 统一对话和输入框左右边界，提高辅助信息、表单和操作按钮的字号与对比度。
- 简历默认使用阅读视图，标准排版的正文默认为 16px，并随面板宽度换行。底部阅读字号只控制屏幕放大，排版面板的字号会改变文档本身；切换 A4 预览后启用整页缩放。
- 阅读放大只在屏幕生效，打印使用当前简历保存的真实字号、间距和留白。
- 900px 以下切换为“对话 / 简历”单栏，减少窄屏同时显示两栏造成的挤压。
